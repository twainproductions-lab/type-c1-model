# Type C1 Apartment Model

Interactive 3D model of the Type C1 unit (3 bedrooms, 2 bathrooms, 1,012 sq ft), traced from the brochure plan and scaled to 10,300 × 9,450 mm with 2,635 mm ceilings (measured on site).

Open `index.html` in a browser, or view it via GitHub Pages.

- **Shell / Furnished**: bare plan, or warm-luxe interior with a U-shaped kitchen
- **3D, Plan, Eye level**: orbit views
- **Walk inside**: stand at 1.65 m and walk with W A S D, arrow keys or the on-screen pad
- **Door open / closed**: three-panel glass pocket door to the kitchen
- **Front door view**: charcoal front door, porch tiles and an 830 × 420 mm oak shoe cabinet outside

`references/` holds the dimensioned kitchen plan and elevations, the overview render and depth map used for image-generation prompts, and a view of the front door and shoe cabinet.
